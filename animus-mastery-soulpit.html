Animus Mastery & SoulPit

Progressao por criaturas

Sistemas que adicionam progressao baseada em criaturas derrotadas.

Experiencia e alma

Permite ganhar mais experiencia e obter itens especiais de alma ao derrotar monstros.

Sistema boostado

O sistema esta boostado em nosso servidor.

Animus Mastery

+2% Bonus inicial Monstros dominados
+0.2x Escala A cada 3 criaturas
+25% Limite Experiencia maxima

Dominio de criaturas

Monstros com Animus Mastery concedem +2% experiencia.

Crescimento progressivo

A cada 3 criaturas dominadas, o multiplicador aumenta em +0.2x.

Incentivo de farm

Quanto mais criaturas desbloqueadas, maior a experiencia recebida.

Anonymous Mastery

Sistema de Custom Soul Core adicionado para criaturas customizadas.

🔮 8% Chance padrão Pode variar conforme a criatura
🧿 +1 Progresso Por vitória com Custom Soul Core
✨ EXP Bônus contra customs Criaturas elegíveis

Custom Soul Core

Monstros custom sem Soul Core oficial podem dropar seu próprio Custom Soul Core.

Alma salva no core

O core salva automaticamente a alma do monstro derrotado e mostra no look a qual criatura pertence.

Uso no Obelisco

O Custom Soul Core pode ser usado normalmente no Obelisco da Soul Pit, como um Soul Core oficial.

Como funciona

  • O core salva automaticamente a alma do monstro derrotado.
  • Ao dar look, é possível visualizar de qual criatura aquele core pertence.
  • Cada vitória usando um Custom Soul Core concede +1 progresso na Anonymous Mastery.

Comando

  • !mastery agora exibe Animus Mastery.
  • !mastery agora exibe Anonymous Mastery.
  • A nova proficiência concede bônus de EXP contra criaturas custom elegíveis.

Monstros elegíveis

  • Void / Netherbound.
  • Fallen Usurpers.
  • True Asuras.
  • Sanctum: Firen, Firzen e Frezee.

SoulPit

Desafio em arena

Jogadores enfrentam ondas de criaturas em uma pequena arena para desbloquear Animus Mastery.

Soul Core

Obtenha o Soul Core da criatura e use no SoulPit para iniciar o desafio.

Desbloqueio

Ao derrotar os inimigos, o Animus Mastery da criatura e liberado.

Soul Cores e itens

Encontrando Fiendish

  • Use a magia exiva moe res.
  • Use o item Radar Boss Portable, disponivel na Store.

Drops de Fiendish

  • Soul Core: 50% de chance.
  • Soul Core da propria criatura: 15% de chance.
  • Soul Prism: 10% de chance.

Uso

  • Ativar desafios no SoulPit.
  • Desbloquear bonus extras de experiencia nas criaturas.
